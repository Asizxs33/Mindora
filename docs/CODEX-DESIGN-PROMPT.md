# Промпт для Codex дизайнера Mindora

Скопируй текст ниже в Codex в корне клонированной Mindora. Приложи свой референс, если он есть.

```text
Ты работаешь над дизайном Mindora в репозитории Asizxs33/Mindora.
Прочитай AGENTS.md и docs/TEAM.md, особенно раздел «Контракт между UI и core».

Сделай редизайн по приложенным референсам. Можно менять композицию, навигацию,
разметку страниц, шрифты, цвета, иконки и иллюстрации. Сохрани русский интерфейс
и используй иконки вместо эмодзи. Проверь десктоп и телефон.

Работай в отдельной ветке design/redesign от актуальной main. Редактируй только ui/.
Для всех доступных экранов используй данные, переданные контроллером. Перенеси
действующие id, имена полей, data-* атрибуты и состояния кнопок в новую разметку.
Сохрани сигнатуры импортируемых функций. Если макет требует нового поведения,
опиши его для разработчика в сообщении или PR.

Запусти npm start, затем npm run check и npm test. В браузере проверь поиск цели,
открытие курса, блокировку этапов, квиз, проверку постера и формулы, сохранение работ,
скачивание SVG/CSV, прогресс после перезагрузки и меню на телефоне. Покажи скриншоты
главной и хотя бы одного изменённого внутреннего экрана.

Закоммить изменения в свою ветку, отправь её в origin и открой PR в main для проверки.
В PR опиши визуальные изменения и результаты проверок. Слияние выполнит владелец.
```
